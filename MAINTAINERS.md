# Maintainers

Open Commerce is supported by Solverine.

## Current Maintainer Group

| Name or Group | Role | Scope |
| --- | --- | --- |
| Solverine | Founding maintainer | Project direction, governance, release decisions, dataset and schema review. |

## Maintainer Expectations

- Review source-backed dataset changes with care.
- Ask for evidence when marketplace economics claims are unclear.
- Keep discussions focused on Open Commerce as an economic intelligence layer, not an operational OMS or connector.
- Prefer public design discussion for compatibility-affecting changes.

## Becoming a Maintainer

Regular contributors may be invited as maintainers after demonstrating consistent judgment in at least one area:

- Dataset quality.
- Schema design.
- Profit and forecast modeling.
- SDK and agent integration.
- Documentation and contributor experience.

Maintainer changes should be recorded in a pull request and acknowledged by existing maintainers.
