# Open Source Program Readiness

Open Commerce is structured to be suitable for future OSS maintainer and infrastructure support programs.

## Current Readiness

- Apache-2.0 license.
- Public contribution guide.
- Governance and maintainer model.
- Issue and PR templates.
- CI validation for schemas, datasets, markdown, and contribution files.
- First-class skill library with interface specs, examples, and future MCP support notes.
- Starter SDK and tests.
- Roadmap and architecture documentation.

## Next Improvements

- Add verified official source references to starter datasets.
- Add tests that execute core skills from interface examples.
- Publish initial project website or documentation site.
- Add release automation.
- Add security contact and maintainer aliases after the public repository is configured.
- Build a first set of community issues with labels.
