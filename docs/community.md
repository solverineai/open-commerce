# Community

Open Commerce is designed for public GitHub Issues, Pull Requests, and Discussions.

Wiki and Projects should remain disabled so durable project knowledge stays in versioned repository files and tracked issues.

## Recommended Labels

- `good-first-issue`
- `help-wanted`
- `dataset`
- `schema`
- `forecast`
- `profit-engine`
- `marketplace`
- `documentation`

## Recommended Discussion Categories

- Announcements.
- Ideas.
- Dataset sources.
- Schema proposals.
- Agent integrations.
- Questions.

## Issue Routing

- Dataset gaps should use the dataset issue template.
- Schema changes should use the schema issue template.
- Calculation bugs should use the bug report template.
- Long-term ideas should start in Discussions before becoming issues.

## Pull Request Review

Maintainers should review for scope, evidence quality, compatibility, and whether the change strengthens Open Commerce as an economic intelligence layer.
