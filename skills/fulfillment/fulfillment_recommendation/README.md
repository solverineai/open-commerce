# fulfillment_recommendation

Recommend fulfillment method or action using cost, delivery promise, inventory, and marketplace context.

## Inputs

- Order or shipment context.
- Inventory availability.
- Carrier options.
- Shipping cost estimates.
- Marketplace service constraints.

## Output

Returns recommended fulfillment option, rationale, risks, and missing data.

## Notes

This skill is advisory by default. Downstream automation must separately authorize shipment changes.
