# break_even_analysis

Calculate the unit price or sales volume needed to break even.

## Inputs

- Unit product cost.
- Variable fees and costs.
- Fixed costs.
- Target profit.
- Quantity.

## Output

Returns break-even unit price and the cost assumptions used.

## Notes

Break-even analysis is sensitive to whether fees are fixed, per-unit, percentage-based, or dataset-derived. State the basis clearly.
