# Governance

Open Commerce is a founder-led open source project supported by Solverine and designed for community-driven contributions.

## Model

- Founder-led direction for mission, scope, and release priorities.
- Maintainer review for datasets, schemas, engine changes, SDK surfaces, and governance updates.
- Community-driven contribution through Issues, Pull Requests, and Discussions.
- Transparent decision records for changes that affect compatibility, trust, or ecosystem direction.

## Project Scope

Open Commerce is not an OMS, ERP, WMS, or marketplace connector. The project focuses on standards, datasets, economic intelligence, forecast interfaces, agent infrastructure, and related validation tools.

## Decision Principles

- Accuracy before coverage.
- Source-backed datasets before convenience.
- Stable schemas before rapid surface expansion.
- Clear contribution paths before advanced automation.
- Interoperability with agent frameworks and commerce systems.

## Maintainer Responsibilities

- Protect the project mission and positioning.
- Review source quality for dataset contributions.
- Maintain backward compatibility where reasonable.
- Keep governance, contribution, and roadmap documents current.
- Label issues and PRs so new contributors can participate.

See [DECISION_PROCESS.md](DECISION_PROCESS.md) for the decision workflow.
